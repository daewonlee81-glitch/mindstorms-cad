# 수업 도면 (Class files)

선생님이 학생에게 나눠 줄 도면을 올리는 폴더입니다. 여기에 올린 파일은 캐드의 **📥 수업 도면** 목록에 나타납니다.

- 반(수업)마다 폴더를 하나씩 만듭니다. 예: `classes/월수 3시반/1주차 기본 로봇.ldr`
- 올릴 수 있는 파일: `.ldr`, `.mpd`, `.zip` (캐드의 "저장"으로 받은 .ldr에는 블록 프로그램과 시뮬레이터 설정도 들어 있습니다)
- 올리는 방법: 캐드의 📥 수업 도면 → "선생님: 도면 올리기" → 반 이름 입력 → "GitHub 업로드 열기" → 파일을 끌어 놓고 **Commit changes**
- 파일 이름이 목록에 보이는 이름입니다. 앞에 `1주차`, `2주차`처럼 번호를 붙이면 순서대로 정렬됩니다.
- 올린 뒤 1~2분 안에 목록에 나타납니다. 지우거나 고칠 때도 GitHub에서 같은 파일을 수정하면 됩니다.
- 올리려면 이 저장소의 공동작업자(Collaborator) 권한이 필요합니다.
