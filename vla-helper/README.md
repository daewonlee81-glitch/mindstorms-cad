# 🤖 VLA 도우미 사용법

**VLA 도우미**는 내 PC에서 돌아가는 작은 프로그램입니다. MindStorms CAD 로봇 시뮬레이터가 **로봇 앞 카메라 그림과 지시 문장**(예: "빨간 칸으로 가")을 보내면, 도우미가 **바퀴를 어떻게 움직일지** 계산해서 돌려줍니다.

- 인터넷 서버를 쓰지 않습니다. 모든 계산은 **내 PC 안에서만** 합니다.
- 처음 설치할 때만 인터넷이 필요합니다.

---

## 준비물

| 항목 | 내용 |
|---|---|
| 컴퓨터 | Windows 10/11 또는 macOS (Linux도 가능) |
| 브라우저 | **Chrome** 또는 **Edge** (Safari는 안 됨) |
| 인터넷 | 처음 설치할 때만 (약 50MB 내려받음) |

---

## 1단계 · 도우미 내려받기

1. MindStorms CAD를 열고 위쪽에서 **로봇 시뮬레이터**를 누릅니다.
2. 오른쪽 칸을 아래로 내리면 **🤖 VLA 도우미**가 있습니다. **⬇ 도우미 내려받기**를 누릅니다.
3. 내려받은 `vla-helper.zip`의 **압축을 풉니다**. 바탕화면에 풀면 찾기 쉽습니다.

> 압축을 풀지 않고 zip 안에서 바로 실행하면 동작하지 않습니다. 꼭 압축을 풀어 주세요.

---

## 2단계 · 도우미 켜기

### Windows

1. 압축을 푼 `vla-helper` 폴더에서 **`start-windows.bat`**을 더블클릭합니다.
2. 보안 경고가 나오면 실행을 허용합니다.
   - 파란 창 **"Windows의 PC 보호"**: **추가 정보 → 실행**
   - **"파일 열기 - 보안 경고"**: **실행**
3. 검은 창이 열리고 준비가 시작됩니다. **처음 한 번은 1~3분** 걸립니다.

### Mac

1. **`start-mac.command`**를 **오른쪽 클릭 → 열기 → 열기**로 실행합니다.
   더블클릭하면 "확인되지 않은 개발자" 창이 뜨고 열리지 않습니다.
2. 터미널 창이 열리고 준비가 시작됩니다. 처음 한 번은 1~3분 걸립니다.

### 이렇게 보이면 성공입니다

```
============================================================
 RoboMakers VLA 도우미 1.0  —  ws://127.0.0.1:8765
 모드: 연습 모드 (규칙 기반, AI 모델 아님)
 ...
```

- ⚠️ **이 검은 창을 끄지 마세요.** 끄면 도우미도 꺼집니다. 다 쓴 다음에 닫으면 됩니다.
- 잘 켜졌는지 확인하려면 브라우저 주소창에 `http://127.0.0.1:8765`를 입력해 보세요. **"✅ VLA 도우미가 켜져 있습니다"**가 보이면 됩니다.

---

## 3단계 · 웹 CAD와 연결하기

1. 로봇 시뮬레이터 오른쪽의 **🤖 VLA 도우미** 칸에서 **[연결]**을 누릅니다.
2. Chrome이 **"…이(가) 로컬 네트워크의 기기에 연결하려고 합니다"** 같은 창을 띄우면 **[허용]**을 누릅니다.
   - 도우미가 같은 PC에 있어서 묻는 것입니다. 허용해도 다른 기기에는 연결하지 않습니다.
3. 동그라미가 **🟢 초록색**이 되고 **"연결됨 · 연습 모드"**가 보이면 성공입니다.

> 한 번 연결해 두면 다음부터는 시뮬레이터를 열 때 자동으로 다시 연결합니다. 도우미는 먼저 켜 두어야 합니다.

---

## 4단계 · 첫 주행

1. 왼쪽 블록 목록 맨 아래의 **🤖 VLA**를 누릅니다.
2. **「👁️ VLA로 주행 · 지시: ___」** 블록을 **「프로그램 시작할 때」** 아래에 붙입니다.
3. 지시 칸에 **`빨간 칸으로 가`**라고 씁니다.
4. 매트를 **라인 트레이싱**으로 고르고 **▶ 실행**을 누릅니다.
5. 로봇이 제자리에서 돌며 빨간색을 찾고, 찾으면 그쪽으로 가서 멈춥니다.
   - **로봇 앞 카메라**에 로봇이 보는 그림이 나옵니다.
   - **💬** 줄에는 도우미가 무엇을 하고 있는지 나옵니다 (예: "빨강 보임", "빨강 도착").

### 연습 모드가 알아듣는 말

지금 도우미는 **연습 모드**입니다. AI 모델이 아니라 정해진 규칙으로 움직이며, 연결 확인과 수업 시연을 위한 모드입니다.

| 지시에 이 말이 있으면 | 로봇이 하는 일 | 예 |
|---|---|---|
| 빨강·주황·노랑·초록·파랑 (빨간, 파란…) | 그 색을 찾아 돌다가 그쪽으로 가서 멈춤 | `파란 칸으로 가` |
| 선, 라인 | 검은 선을 따라감 | `검은 선을 따라가` |
| 멈춰, 정지 | 멈춤 | `멈춰` |

영어(red, line, stop), 일본어, 중국어, 스페인어 낱말도 알아듣습니다.

## 5단계 · 주행 기록 (AI 학습 데이터 모으기)

진짜 VLA 모델을 학습시키려면 **잘한 주행의 기록**이 많이 필요합니다.

1. VLA 도우미 칸에서 **⏺ 주행 기록**에 체크합니다.
2. **아무 블록 프로그램**이나 실행합니다. 직접 짠 프로그램이든, 🎓 학습으로 만든 프로그램이든 다 됩니다.
3. 프로그램이 실행되는 동안 0.1초마다 **카메라 그림 + 로봇이 움직인 속도·회전**이 저장됩니다.
4. 멈추면 **💾 저장됨 · 85장 · (폴더 위치)**가 나옵니다.

저장 위치는 `vla-helper/recordings/날짜_시간_지시/` 폴더입니다.

```
recordings/20261115_042310_빨간_칸으로_가/
  ├ images/00001.png …   로봇 앞 카메라 (96×72)
  ├ steps.jsonl          그림마다 시간·요 각도·위치·행동(속도 mm/s, 회전 °/s)
  └ meta.json            지시 문장, 매트, 로봇 이름, 걸린 시간
```

💡 **잘된 주행만 남기고 실패한 기록 폴더는 지우세요.** 좋은 예만 모아야 좋은 모델이 나옵니다.

💡 지시 문장은 「VLA로 주행」 블록의 지시에서 가져옵니다. 이 블록이 없으면 "블록 프로그램"으로 저장되니, `meta.json`의 `task`를 직접 고쳐 주세요 (예: "노랑→초록→파랑 차고에 차례로 주차").

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| [연결]을 눌러도 "연결하지 못했습니다" | 도우미 검은 창이 열려 있는지 확인하세요. `http://127.0.0.1:8765`가 열리는지도 확인하세요. |
| Chrome 허용 창에서 **차단**을 눌렀음 | 주소창 왼쪽 아이콘 → **사이트 설정** → **로컬 네트워크**(또는 "기기의 앱") → **허용** → 새로고침 |
| 검은 창에 "포트 8765 을(를) 열 수 없습니다" | 도우미가 이미 켜져 있습니다. 다른 검은 창을 찾아 닫고 다시 켜세요. |
| 검은 창이 바로 닫혀 버림 | 인터넷 연결을 확인하고 다시 실행하세요. 처음 실행할 때는 설치 파일을 내려받아야 합니다. |
| Mac에서 "확인되지 않은 개발자" | 더블클릭 대신 **오른쪽 클릭 → 열기**로 실행하세요. |
| 로봇이 빙글빙글 돌기만 함 | 카메라에 그 색이 안 보이는 것입니다. 매트에 그 색이 있는지 확인하세요. |
| 학교 PC라 설치가 막힘 | 전산 담당 선생님께 `uv`(Python 실행 도구) 설치 허용을 요청하세요. 관리 PC에서는 관리자 정책으로 Chrome 로컬 네트워크 허용을 미리 켜 둘 수도 있습니다. |

### (실험) AI 모델로 실행하기 — 선생님·개발자용

모은 주행 기록으로 SmolVLA를 미세조정한 모델이 있을 때 쓰는 방법입니다. NVIDIA GPU 또는 Apple Silicon Mac을 권장합니다.

```bash
uv run --with "lerobot[smolvla]" server.py --policy policies/smolvla_policy.py --model <학습한 모델 폴더>
```

- `policies/` 폴더에 `load()`와 `act()`가 있는 파이썬 파일을 만들면 다른 모델도 연결할 수 있습니다. `smolvla_policy.py`를 참고하세요.
- `--port 8766`처럼 포트를 바꿀 수 있습니다. 이때 웹 CAD에서도 같은 포트를 써야 합니다 (`localStorage` 의 `mscad.vla.port`).

### 보안

- 도우미는 **이 PC 안(127.0.0.1)에서만** 접속을 받습니다. 같은 와이파이의 다른 기기는 접속할 수 없습니다.
- MindStorms CAD 사이트(GitHub Pages·robomakers.co.kr)와 PC에서 직접 연 파일에서 온 연결만 받습니다.
